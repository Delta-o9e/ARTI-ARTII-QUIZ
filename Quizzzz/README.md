# Adaptive Resonance Theory Quiz

A Vercel-ready, dependency-free interactive quiz based strictly on the supplied PPT.

## Deploy on Vercel
1. Upload this folder/repository to GitHub.
2. In Vercel, choose **Add New → Project**.
3. Import the GitHub repository.
4. Framework Preset: **Other**.
5. Build Command: leave empty.
6. Output Directory: leave empty.
7. Deploy.

You can also drag the project folder into Vercel's deployment interface.
